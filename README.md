Dice Game 🎲

Project Description

This is a simple dice game built using Flutter.

The player rolls two dice, and the app calculates their total.

- If the total is 10 or more, the app displays the happy image.
- If the total is less than 10, the app displays the sad image.
- The Roll Dice button generates two random numbers from 1 to 6.
- The Reset button returns both dice to 1.

Features

- Random dice values.
- Automatic total calculation.
- Win and lose images.
- Reset button.
- Simple user interface.

Technologies Used

- Flutter
- Dart

Project Files

- "lib/main.dart": Main application and game logic.
- "lib/dice.dart": Dice widget.
- "assets/you_win.png.jpeg": Win image.
- "assets/you_lose.png.jpeg": Lose image.
- "pubspec.yaml": Project configuration and assets.

How to Run

1. Install Flutter.
2. Open the project folder.
3. Run "flutter pub get".
4. Run "flutter run -d chrome".
